# 🏥 AI-Powered Smart Hospital Bed Queue Management System

A production-ready AI-integrated Hospital Queue & Bed Management System built as a Final Year Project.

## 🚀 Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React.js (Vite), Bootstrap 5 |
| Backend | Spring Boot (Java 21), JWT Auth |
| Database | MySQL 8.0 |
| AI Module | Python, Flask, Scikit-Learn |

## 📁 Project Structure

AI-Powered-Smart-Hospital-Queue-System/
├── backend/         Spring Boot REST API
├── frontend/        React.js UI
├── ai-module/       Python Flask AI/ML
├── docs/            Documentation
├── .gitignore
└── README.md

## ✨ Features

- Patient Registration & Queue Management
- Real-time Bed Availability Tracking
- AI-based Patient Priority Prediction
- Waiting Time Prediction
- Hospital Recommendation System
- Admin Dashboard with Reports
- JWT Authentication & Role-based Access
